# `.handoff/` — auto-claude runtime state

This directory is the on-disk durable state for the **auto-claude orchestration
framework** (see `scripts/auto_claude/`). One Claude Code session emits state
here; the watchdog reads it; a successor session picks up where the previous
one left off.

## What's tracked vs ignored

Tracked in git:

- `.gitkeep` — keeps the directory present
- `.gitignore` — selects what is ignored per-machine
- `README.md` — this file
- `state.example.json` — committed schema reference

Ignored (runtime, per-machine, never committed):

- `state.json` — the live task ledger; single source of truth
- `.lock` / `.watchdog.lock` — single-instance locks
- `.backoff.json` — back-off cooldown after repeated failures
- `events.jsonl` — append-only audit log
- `logs/` — per-session stdout/stderr captures
- `reflog-snapshots/` — `git reflog` snapshots taken before each spawn
- `STATUS.md` / `HANDOFF.md` — generated views (regenerated by the watchdog)
- `HANDOFF-*.md` — legacy hand-written session handoff notes

## State.json is the only source of truth

Markdown views (`STATUS.md`, `HANDOFF.md`) are **generated**, never read.
If you need to know what's running, inspect `state.json` (with `jq`) or read
`STATUS.md` (which is regenerated on every watchdog tick).

## Bootstrapping

```sh
scripts/auto_claude/install.sh    # validates deps, creates state.json from
                                  # state.example.json if missing
```

See `scripts/auto_claude/` for the full framework.
